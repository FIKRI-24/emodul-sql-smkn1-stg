Kegiatan Belajar 1

Pengenalan SQL, XAMPP & Data Definition Language (DDL)

Mengenal sejarah SQL, software database XAMPP/MySQL, pembuatan basis data, serta pengelolaan struktur tabel dengan DDL.

Tujuan Pembelajaran

Setelah mempelajari kegiatan belajar 1 ini, peserta didik diharapkan mampu:

  1. Memahami sejarah, konsep dasar SQL (Structured Query Language), serta pengelompokan perintah DDL, DML, dan DCL.
  2. Mengidentifikasi fungsi paket perangkat lunak XAMPP (Apache, MySQL, PHP, Perl) serta kelebihan dan kekurangan DBMS MySQL.
  3. Mempraktikkan langkah instalasi XAMPP dan menjalankan server MySQL melalui command shell.
  4. Menerapkan perintah DDL untuk mengelola database (CREATE DATABASE, SHOW DATABASES, USE).
  5. Menerapkan perintah DDL untuk membuat dan memodifikasi tabel (CREATE TABLE, SHOW TABLES, DESCRIBE, ALTER TABLE, RENAME TABLE, DROP).
