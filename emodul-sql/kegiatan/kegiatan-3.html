Kegiatan Belajar 3

Data Control Language (DCL) & Keamanan Basis Data

Memahami konsep keamanan database, pembuatan pengguna baru (CREATE USER), serta pengelolaan hak akses otorisasi (GRANT & REVOKE).

Tujuan Pembelajaran

Setelah mempelajari kegiatan belajar 3 ini, peserta didik diharapkan mampu:

  1. Memahami pentingnya konsep otorisasi, autentikasi, dan keamanan data dalam sistem manajemen basis data relasional (RDBMS).
  2. Menerapkan sintaks CREATE USER untuk membuat akun pengguna database baru dengan autentikasi kata sandi.
  3. Menerapkan perintah GRANT untuk memberikan hak akses manipulasi tertentu (SELECT, INSERT, UPDATE) pada database/tabel.
  4. Menerapkan perintah SHOW GRANTS FOR untuk memeriksa izin akses yang aktif pada suatu akun pengguna.
  5. Menerapkan perintah REVOKE untuk mencabut kembali izin hak akses pengguna.
  6. Mempraktikkan seluruh ragam query SQL (DDL, DML, DCL) secara langsung melalui simulator Playground SQL interaktif.
