Capaian & Alur Tujuan Pembelajaran (CP & ATP)

Mata Pelajaran Basis Data — Fase F / Kelas XI Program Keahlian Rekayasa Perangkat Lunak (RPL) SMK Negeri 1 Sintuk Toboh Gadang.

Capaian Pembelajaran (CP) Elemen Basis Data

Pada akhir fase F, peserta didik mampu mengidentifikasi dan membedakan jenis-jenis perintah SQL (Structured Query Language), memahami instalasi perangkat lunak basis data relasional (DBMS XAMPP/MySQL), serta mampu menerapkan sintaks Data Definition Language (DDL), Data Manipulation Language (DML), dan Data Control Language (DCL) untuk perancangan, pengelolaan, dan pengamanan basis data relasional dalam pengembangan perangkat lunak.

Alur Tujuan Pembelajaran (ATP) per Kegiatan Belajar

Tahap 1 • Kegiatan Belajar 1

Pengenalan SQL, XAMPP, dan Data Definition Language (DDL)

Peserta didik mampu memahami sejarah SQL, melakukan instalasi server MySQL pada XAMPP, membuat database dan tabel, serta memodifikasi struktur data menggunakan perintah CREATE, ALTER, RENAME, dan DROP.

Tahap 2 • Kegiatan Belajar 2

Pengelolaan Record dengan Data Manipulation Language (DML)

Peserta didik mampu melakukan manipulasi data relasional meliputi penambahan baris (INSERT INTO), penyeleksian dan pemfilteran data (SELECT, WHERE, pola LIKE), serta pengubahan (UPDATE) dan penghapusan data (DELETE).

Tahap 3 • Kegiatan Belajar 3

Pengamanan Akses dengan Data Control Language (DCL) & Praktik Mandiri

Peserta didik mampu menerapkan keamanan basis data relasional dengan membuat akun pengguna baru (CREATE USER), memberikan hak akses (GRANT), dan mencabut hak akses (REVOKE) serta menguji seluruh query pada simulator SQL.
