Petunjuk Penggunaan Modul

Panduan Penggunaan E-Modul

Selamat datang di E-Modul Interaktif SQL. Pahami aturan sistem pembelajaran bertahap (sequential learning) dan mekanisme pembukaan materi di bawah ini.

Alur & Aturan Pembelajaran Berurutan

E-Modul ini menerapkan alur pembelajaran terstruktur (mastery learning). Siswa tidak dapat langsung melompat ke materi berikutnya tanpa menyelesaikan tahapan prasyarat:

  1. 1. Membaca Panduan Modul (Tahap Ini)

    Pahami cara kerja e-modul. Klik tombol konfirmasi di bawah untuk membuka menu Capaian & Tujuan Pembelajaran (CP & ATP).

    Bebas Diakses
  2. 2. Mempelajari Capaian & Alur Tujuan Pembelajaran (CP & ATP)

    Pahami target kompetensi yang harus dikuasai pada mata pelajaran Basis Data. Setelah selesai membaca CP/ATP, Kegiatan Belajar 1 akan otomatis terbuka.

    Terbuka Setelah Membaca Panduan
  3. 3. Kegiatan Belajar 1 (Pengenalan SQL & DDL) — Syarat Nilai Latihan: Minimal 80 (KKM ≥ 80)

    Pelajari uraian materi, tonton video, dan kerjakan latihan soal. Nilai latihan harus memperoleh minimal 80 (KKM ≥ 80) agar Kegiatan Belajar 2 terbuka.

    Wajib Nilai Latihan ≥ 80
  4. 4. Kegiatan Belajar 2 (Data Manipulation / DML) — Syarat Nilai Latihan: Minimal 80 (KKM ≥ 80)

    Pelajari perintah INSERT, SELECT, UPDATE, DELETE. Raih nilai latihan minimal 80 untuk membuka Kegiatan Belajar 3.

    Wajib Nilai Latihan ≥ 80
  5. 5. Kegiatan Belajar 3 (Data Control / DCL) & Praktik Mandiri

    Pelajari manajemen hak akses pengguna (GRANT & REVOKE). Tuntaskan latihan dengan nilai minimal 80 (KKM ≥ 80) untuk membuka Evaluasi Akhir.

    Wajib Nilai Latihan ≥ 80
  6. 6. Evaluasi Akhir Pemahaman SQL

    Ujian komprehensif 10 butir soal untuk mengukur keseluruhan pemahaman konsep dan perintah SQL Anda.

    Tahap Akhir Modul

Playground Editor SQL (Bebas Diakses Kapan Saja)

Fitur Editor SQL tidak dikunci dan dapat Anda gunakan kapan saja untuk mencoba menulis perintah SQL secara mandiri dengan database virtual yang berjalan di browser.

💡 Tips Menjalankan Query di Editor SQL:

  • Gunakan tombol Ctrl + Enter untuk mengeksekusi perintah SQL dengan cepat.
  • Tabel bawaan yang siap dicoba: murid (nisn, nama, alamat, jenis_kel, kelas) dan mapel.
  • Gunakan tombol "Reset Database" jika ingin mengembalikan struktur tabel ke kondisi awal.
